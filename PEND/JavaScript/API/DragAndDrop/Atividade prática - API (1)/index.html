Educa e recicla!♻️

Seja bem-vindo ao jogo "Educa e recicla", um jogo divertido e educativo com a proposta de ensinar a auxiliar na separação dos resíduos!

♻️ Sobre a Reciclagem: A reciclagem é uma prática muito importante para cuidar do meio ambiente. Ela permite que materiais que seriam descartados sejam separados, reaproveitados e transformados em novos produtos. A separação correta dos resíduos ajuda a diminuir a quantidade de lixo enviada aos aterros, economiza recursos naturais e contribui para um ambiente mais limpo e saudável.
